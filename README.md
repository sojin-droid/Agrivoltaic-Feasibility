# 영농형 태양광 — 실행 가능 물량 분석 (25개 분석구역)

경기·충남 15개 시군과 전국 산단 거점을 포함한 **25개 분석구역(원장 물리 코드 30개)**의 200만 필지 전수 원장을 바탕으로, 현행 제도(S0)와 재생에너지지구 지정(S1) 시나리오에서 영농형 태양광 특구 후보의 **실행 가능 물량**을 산정한다. 잠재량이 아니라 개인소유 비율이 낮은 블록의 실행 가능 물량으로 후보를 가린다.

> 별도 공개본입니다. RE100 프레이밍의 기존 사이트(`sojin-droid/Agrivoltaic-Cluster`, Supabase·CLIMADA 기반)와는 다른 갈래로, **실행 가능 물량·구역별 지도(atlas)** 중심으로 재구성한 버전이다.
>
> **공개 사이트 (GitHub Pages)**: https://sojin-droid.github.io/Agrivoltaic-Feasibility/

## 사이트 구성 (레포 루트 = Pages 루트)

| 페이지 | 내용 |
|---|---|
| `index.html` | 개요 — 현행/지정 시 대비, 핵심 지표, 파이프라인 |
| `map.html` · `map_full.html` | 인터랙티브 지도 — 필지 블록·시나리오·개인소유 상한(t)·읍면동 계통 여유 |
| `atlas.html` | 구역별 지도 — 25개 분석구역 각각 S0/S1 블록 지도 + 계통 지도 + 대비 표 |
| `method.html` | 방법론 — 발전량 산식·적격성 필터·블록 클러스터링·판정 규칙 |
| `insight.html` | 인사이트 — 판정 순위·도시 성격 매트릭스·잠재/실행 간극 |
| `assets/` | 로고·용어집(terms.js)·부록(appendix.js) |
| `data/` | 사이트가 로드하는 산출 JSON (판정·블록 폴리곤·계통·수요·소유·산단) |
| `atlas_img/` | 구역별 지도 정적 이미지 (블록 S0/S1 + 읍면동 계통) |
| `pipeline/` | 분석 파이프라인 코드 (`01`~`21` 및 보조 스크립트) |

## 파이프라인 (요약)

`01_clean_parcels` → `02_derive_attrs`(시나리오 적격성) → `15_build_b_regions`(B 거점) → `18_block_production`(25m 연접 블록·50MW 3단 분할·소유 판정) → `20_build_site_data`(사이트 JSON) → `19_predeploy_check`(배포 전 점검).

판정선 50/100MW는 법령 기준이 아닌 연구 가정(정책 시나리오)이며, S2(자연환경보전지역 포함)는 판정 변화 0곳의 상한 참고선이다.

## 갱신 (GitHub Desktop)

1. 파이프라인 재실행 후 `20_build_site_data`로 `data/` 갱신, 필요 시 구역별 지도 이미지 재생성.
2. 변경분을 이 레포 폴더로 복사.
3. GitHub Desktop에서 변경 사항 확인 → 커밋 → **Push origin**.

> 비공개 페이지(`lab.html`·`policy.html`)와 파이프라인 중간 산출물(`*_members.json`·`legacy_*`)은 `.gitignore`로 배포에서 제외한다.
