Verification

재현·검증 체계

SINGLE SOURCE

정본 질의 — 단일 출처

모든 수치는 정본 DB의 표준 질의 모듈에서만 나온다. 이 사이트의 데이터 파일도 그 모듈을 직접 불러 생성 — 판정 SQL이 두 곳에 존재하지 않는다.

TOUCHSTONE

시금석 — 기준값 상수

현행법 기준값(필지 수·㎡)이 상수로 박혀 있고, export 시 재조회값과 정확 일치하지 않으면 파일 생성이 중단된다.

ADDITIVITY

가산성 검사

세 풀(진흥 밖·보호·진흥)이 서로소이므로 R0+풀 합 = R3가 정확히 성립해야 한다 — 어긋나면 게이트가 막는다.

SITE GATE

공개 전 자동 게이트

무효·구세대 수치, 금지 표현, 외부 자원 로드, 본문 하드코딩 수치를 공개 전에 자동 검사한다. 새 함정이 발견되면 문서보다 먼저 검사 코드에 추가한다.

이격거리(주거 이격)가 이 판에 없는 이유. 시군 조례의 이격거리 실측 반영분은 2026-08-10 전량 무효 판정했다(산출 검증 실패). 현행 제도는 영농형 태양광에 대해 이격거리 상한제(조례 상한 200m)로 정비되는 방향이며, 이격 반영값은 재도출·검증을 거쳐 별도 판(2판)으로 병기한다 — 이 판의 값과 섞지 않는다.
공간 미분해 배제 항목 17종(하천·문화유산 등)은 현재 판에 반영되지 않았다 — 따라서 강한 배제(HARD) 계열 값은 하한이다. 분해 레이어 조달 시 판을 올려 반영한다.
