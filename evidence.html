전체 표

표 1. 구역 조합(R0–R3)별 설치 가능 필지 수와 면적 — 전국

각 행은 독립 조합(단계 사다리 아님). R1−R0 = 보호구역 증분, R2−R0 = 진흥구역 증분, R0+두 증분 = R3 — 세 부분이 서로 겹치지 않아 정확히 가산된다[12][14].

표 2. 구역 조합(R0–R3)별 설치 가능 필지 수와 면적 — 간척 확정 농지

간척 = 농어촌공사 지구·공구 원장 등재분(민간 매립 미등재)[3][4]. 간척 농지는 대부분 농업진흥구역 안에 있어, 규모가 진흥구역 개방(R2)에서 움직인다.

표 3. 구역별 증분 분해 — 농업진흥지역 밖 · 농업보호구역 · 농업진흥구역

각 증분 = 해당 구역 안에서 나머지 판정 조건(지목·구조물·경사·용도지역 3종·실경작)을 모두 통과한 필지의 합. 표 1에서 산술로만 유도(R1−R0, R2−R0). 정본 DB 조회값[12], 단위 필지 수·km².

표 4. 소유 유형별 실경작 확인 농지 — 간척지 내 법인 · 간척지 내 비법인 · 간척지 외 법인

실경작 확인 농지 기준[2]. 소유는 지적 원장의 유형 구분(개인 식별 아님)[1] — 법인이 농업법인인지는 원장에 없어 구분 못 함(명부 조달 시 정밀화).

표 5. 구역 조합(4) × 이격(2) × 실경작(2) × 집계 단위(2)별 설치 가능 면적 — 32칸 전체

구획 = 필지를 연접 거리 21m로 병합한 성분 중 6.67ha 이상[10][12] · 실경작 전 = 위성 실측 필터(30%) 미적용[2] · 이격 보수 = 주거 200m 상한을 대지 필지 대리로 일률 적용한 하한[11]. 필지→구획 전환에서 현행법 기준은 크게 줄고 진흥지역 개방 계열은 덜 줄어 — 진흥구역 농지가 크게 뭉쳐 있어 병합 문턱을 잘 넘기기 때문 — 사업규모 관점에서는 격차가 더 벌어진다. 지도에서 구획 직접 보기 →
