수치표 — 전체 값 참조

근거: 조합 매트릭스 · 풀 분해 · 소유 세 무리

모든 표는 정본 DB 조회값. 필지 수와 면적(km²)이 1차 산출, MW는 참고 환산(0.045 kW/㎡ 가정).

표 1. 조합 매트릭스 — 전국

각 행은 독립 조합(단계 사다리 아님). R1−R0 = 보호구역 풀, R2−R0 = 진흥구역 풀, R0+두 풀 = R3 — 세 풀이 서로 겹치지 않아 정확히 가산된다.

표 2. 조합 매트릭스 — 간척 확정 농지

간척 = 농어촌공사 지구·공구 원장 등재분(민간 매립 미등재). 간척 농지는 대부분 농업진흥구역 안에 있어, 규모가 진흥구역 개방(R2)에서 움직인다.

표 3. 풀 분해 — 어느 구역에 얼마가 있나

풀 = 해당 구역 안에서 다른 모든 판정 조건(지목·구조물·경사·용도지역 3종·실경작)을 통과한 필지. 매트릭스에서 산술로만 유도(R1−R0, R2−R0).

표 4. 소유 세 무리 — 간척 내 법인 · 간척 내 비법인 · 간척 밖 법인

실경작 확인 농지 기준. 소유는 지적 원장의 유형 구분(개인 식별 아님) — 법인 유형에 농업법인 여부는 원장에 없어 구분 못 함(명부 조달 시 정밀화).

간척 활용 조문이 시행되면 — 세 무리의 처지
